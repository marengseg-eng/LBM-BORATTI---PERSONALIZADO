### Configuração de página (obrigatória)

> ⚠️ **Regra crítica:** `@page` FORA do `@media print`, e NUNCA usar `margin` diferente de zero.
> Com `margin: 15mm`, o browser adiciona bordas brancas, quebra o `flex: 1` dos filhos
> e espreme o conteúdo. O layout de tela (210mm × 297mm) deve ser idêntico ao PDF.

```css
/* @page no topo — fora do @media print */
@page { size: A4 portrait; margin: 0; }

.folha {
  width: 210mm;
  height: 297mm;        /* height fixo = flex:1 funciona nos filhos */
  min-height: 297mm;
  max-height: 297mm;
  page-break-after: always;
  break-after: page;
  overflow: hidden;
  display: flex;
  flex-direction: column;
}

@media print {
  html, body { background: white; margin: 0; padding: 0; width: 210mm; }
  .btn-print { display: none !important; }
  .folha {
    width: 210mm !important;
    height: 297mm !important;
    margin: 0 !important;
    box-shadow: none !important;
    overflow: hidden !important;
    display: flex !important;
    flex-direction: column !important;
  }
  .folha:last-child { page-break-after: auto; break-after: auto; }
  * { print-color-adjust: exact !important; -webkit-print-color-adjust: exact !important;
      box-shadow: none !important; }
  .lista thead, .tabela thead { display: table-header-group; }
}
```

### Anti-espaço-branco: flex:1 por folha

Para eliminar branco no final de cada folha, o **último bloco de conteúdo** recebe `flex: 1`:
- Folha 1: `.cards-grid { flex: 1; align-content: stretch; }`
- Folha 2: `.impacto-row { flex: 1; }`
- Folha 3/4: `.lista { flex: 1; }` (tabela de presença preenche até o rodapé)

Isso **só funciona** porque a `.folha` tem `height: 297mm` fixo (flex container com altura definida).
